# 来源与灵感

本作的机制设计有明确出处。本页只记录已核实的借鉴关系：借鉴的是机制思路，全部文本、数值与内容均为原创。

## 首要来源：《百世成仙》

- 《百世成仙》（Hundred Lives to Immortality），凯菲工作室，Steam，2026-10-08
- 商店页：https://store.steampowered.com/app/5235070/Hundred_Lives_to_Immortality/
- 借鉴并已落地的机制：
  - **传承点赎回**：轮回结算时花有限点数、按品质计价，把装备/功法带入下一世。
  - **前世遗藏**：本世亲手把宝物埋在指定地点，后世亲赴其地取回。
  - **承世玉**：跨世叠加加成的挂饰，可用寿元祭练提升。
  - **因果待办**：未了结的前世因果与未取的遗藏列成清单，逐项勾销。
- **反向声明**：该作官方从未提过开局随机身份/天赋/命格。本作的降生抽选（姓名、出身、命格、天赋、灵根各抽候选再选）是原创设计，不出自该作，请勿误植。

## 调研基础

2026 年 11 月，本项目做过一轮系统调研：100 款修仙/轮回类游戏、100 本轮回修仙小说、24 个 GitHub 开源仓库，逐条解析可借鉴机制。除《百世成仙》外，已实际落地的借鉴包括：

| 落地内容 | 来源 |
| --- | --- |
| 分叉路线探索（五层路线、每层三节点） | 《杀戮尖塔》的路线结构 |
| 委托板（接取式支线） | 《古剑奇谭三》 |
| 限时帖（双重倒计时、声望结算） | 小说《修真聊天群》 |
| 日常委托（按月刷新、入地点触发） | 小说《我的微信连三界》 |
| 地点签到与签到图鉴 | 小说《修仙：神级签到系统》 |
| 封印之蛋收集（集齐兑换前世遗藏线索） | 《轩辕剑六》* |
| 道德分叉事件（行善 / 夺宝两支） | 《修仙故事：轮回》 |
| 经营日常随机危机 / 惊喜事件 | 《了不起的修仙模拟器》 |
| 事件分包（本篇 / 外传按世数解锁） | 《古剑奇谭二》 |
| 事件分批投放（按版本钉住牌堆） | 《轩辕剑外传：穹之扉》 |
| 按地点排布事件掉落 | 《轩辕剑柒》 |
| 锻造法宝（矿石七阶、坊市矿行） | 《造化仙缘》 |
| 副职熟练度与破限 | 小说《苟在神诡求长生》 |

\* 《轩辕剑六》在调研时未找到 Steam 商店页，该来源未完全核实；机制本身经评估后采用，特此注明。
