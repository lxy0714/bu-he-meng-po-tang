# 设计思路

这款游戏的每条核心规则都不是随手定的：2026 年 11 月 8 日起，经过多轮逐条定夺（记录为 Q1–Q42 与 D-1–D-6），先把规则谈死、写进 625 项的开发计划，再逐项实施。本页讲清这些决定背后的取舍。

## 一句话

**死亡不是终点，是进度单位。** 你扮演一个带着封印前世记忆的灵魂，一世接一世地活、死、再来，用每一世换取跨世积累，最终成仙。

## 轮回规则

- **最差开局**：废灵根凡人，前世记忆被封印——起点越低，每一世的成长越有分量。
- **修为只留一成**（Q3 / D-6）：死后修为保留 10% 结转下一世。留得太少，每世白干；留得太多，死亡没有代价。一成是反复权衡后的刻度。
- **记忆按死法保留**（Q12）：坐化留三成、战死留一成、横死不留；境界每高一境多留半成，封顶五成。死法因此成为一种策略：怎么死，和活多久同样重要。
- **走火入魔分轻重**（Q35，改 Q12）：早期版本走火入魔直接魂飞魄散，玩家反馈太狠。现改为轻度重伤 + 修为折损、重度才魂飞魄散，且持有抢救道具可消耗一件救回一次。
- **本命法宝**（Q9 / Q40）：第一世没有法宝；死后首次轮回挑一件带走，之后每世可换。法宝共 28 件，按功能强度分七档使用门槛——未达门槛只能封存，境界到了自动解封。轮回结算只列本世真正持有且达门槛的法宝。

## 降生：随机与自选并存

姓名、出身、命格、天赋、灵根每一项都可以独立选择「随机」或「自选」；随机时从大池（姓名 48 / 出身 36 / 命格 18 / 天赋 24 / 灵根 10）各抽 3 个候选再挑。随机给命数感，自选给掌控感，两者不互相排斥。

## 三层货币，分工不混用

- **轮回点**（跨世主货币）：按本世评级发放（S 6 / A 4 / B 3 / C 2），另按本世新集齐的记忆碎片分档追加。开局可逐点分配到战力/神识/机缘/体魄（单项上限 10）、花 3 点重置天赋与灵根候选、或购买开局强化。
- **传承点**：只用于轮回结算时赎回装备与功法（借鉴《百世成仙》，见 [来源与灵感](sources.md)）。
- **灵石**（局内货币）：死后全清零，每世固定 50 开局——杜绝靠囤钱滚雪球，每一世都要重新挣。

## 判定：为什么不用一把骰子打天下

早期全游戏统一用 d150 判定，很快发现问题：d150 的标准差约 43，属性修正只有个位数，掷骰结果几乎与养成无关。Q34 因此改为**分系统骰子**，且每把骰子的上下限由相关属性动态决定：

| 系统 | 骰子 | 上下限依据 |
| --- | --- | --- |
| 斗法 / 决斗 / 复仇 | d20 | 战力 |
| 突破 | d100 | 境界、机缘 |
| 探索事件 | d80 | 机缘 |
| 副职 | d60 | 副职熟练度等级、神识 |
| 社交 | d40 | 好感、机缘 |
| 宗门差事 | d50 | 宗门位阶、体魄 |
| 记忆保留 | d100 | 百分比口径（Q12） |

配套的**相对差距原则**：所有判定的难度都按「玩家相关能力 vs 目标档位」的差距算——境界高了，遇到的敌手和事情也同步变强，不存在高境界碾压低档位内容的阶段。

## 细时钟：时间按月走

Q37 把时间单位从「年」细化到「月」（1 年 = 12 个月）：修炼 12 月、探索 3 月、斗法 1 月、旅行按距离 1–6 月，全部耗时进配置表；年龄由累计月份推导，寿元（120 岁 = 1440 月）按月结算；限时帖倒计时改按天/月，日常委托每月刷新一批。时间因此成为可感知的资源，而不是一个跳动的数字。

## 内容与工程

- **内容全配置化**：事件（80 条）、地点（12）、NPC（12）、法宝（28）、功法、敌人等全部静态内容都在 JSON 配置表里，加载时做结构与引用校验，改内容不用改代码。
- **存档工程先行**：存档存储抽象层、字段注册表、PRNG 状态保存恢复在早期就落地——存档格式稳定、可迁移，也是本次能顺利导出开源版的基础。
- **规则先行**：整局规则在新游戏时设定并锁定，游戏内只读——关于第一世的规则中途改动会破坏整局一致性，所以入口只在开局。

## 难度定位

中等偏虐（Q10）。突破有连败保底（每次失败下次难度 −5，叠满 −20），休整回血 60% 并附带少量修为——虐，但不堵死。
