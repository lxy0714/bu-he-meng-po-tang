# 玩法说明

## 开局

1. 主菜单点「新游戏」：先进入**规则设定页**，整局 19 条规则（难度、轮回口径等）逐项可改，默认是推荐值；确认后规则锁定，游戏内只能查看不能改。
2. **降生抽选**：姓名、出身、命格、灵根、天赋每一项各抽 3 个候选，逐项选「用抽到的」或「自选」。
3. **轮回点分配**（第二世起）：把跨世攒下的轮回点分配到战力 / 神识 / 机缘 / 体魄，或购买开局强化。
4. 进入第一世：废灵根凡人，灵石 50，前世记忆封印。

## 一世的日常

时间按月流逝，每个动作都耗时；年龄与寿元（120 岁）按月结算，注意「寿元将尽」提示。

- **修炼**（12 个月）：涨修为。
- **突破**：修为达到当前小阶门槛后可尝试突破到下一小阶 / 境界（炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫，每境四阶）。判定掷 d100；失败不惩罚，且有连败保底（每次失败下次难度 −5，叠满 −20）。
- **休整**（1 个月）：回复 60% 气血，附带少量修为。
- **探索**：在地图上旅行（15 个地点，按距离 1–6 个月），探索会触发随机事件（二选一、三选一、道德分叉等，掷探索判定 d80），成功可能掉落功法残页、矿石、法宝；也可以走**五层分叉路线**（战斗 / 精英 / 事件 / 商店 / 休息节点自选路径）。
- **委托与帖子**：委托板接取式支线（同时上限 3 个，无时限）；限时帖有双重倒计时，过期或超时会结算声望，别贪接。
- **签到**：首次到达坊市、青云山门、青冥秘境有一次性签到奖励，记录进跨世图鉴。

## 修炼与经营

- **副职**：炼丹、炼器、灵田、垂钓四门，各有熟练度（用得越多越高），5 / 15 / 30 次破限到熟手 / 精通 / 宗师，成功产出有加成。
- **锻造**：坊市矿行买矿（或探索拾矿），在锻造台炼制法宝——按炼器等级与境界双门槛开放，成功产出 28 件法宝池中的一件。
- **宗门**：加入宗门、做差事攒贡献、晋升位阶（晋升有赐宝）。
- **功法**：学习与参悟功法提升战力；功法熟练度系统在路线图中。
- **斗法**：挑战各地敌手，掷斗法判定（d20）；法宝、功法、境界都折进战力。
- **经济**：坊市买丹药、寄卖丹药换灵石；洞府可建聚灵阵。注意：灵石死后清零，别囤。
- **社交**：12 位 NPC 可结交、拜访，发展为道友 / 师父 / 徒弟 / 道侣 / 仇敌五种关系；好感影响社交判定。

## 死亡与轮回

寿元耗尽坐化、战死、横死，或走火入魔重度，都会结束这一世，进入**轮回结算**：

- 按本世表现评级发放轮回点（S 6 / A 4 / B 3 / C 2），并按本世新收集的记忆碎片数追加。
- 修为只留一成结转；记忆按死法保留（坐化 30% / 战死 10% / 横死 0%，境界加成封顶 50%）。
- 用传承点赎回想带走的装备与功法；挑一件本世持有且已达门槛的本命法宝带走。
- 埋下的前世遗藏、未了的因果会留给下一世处理。

在「轮回历史」页可以查看轮回树、前尘残片与每一世的编年史。

## 主线：前世之谜

收集 9 枚记忆碎片，集齐 1 / 3 / 5 / 7 / 9 枚时逐步揭开前世身份的五章真相；集满有额外奖励，且每世可带前世道果。

## 设置

- 主题三档（浅色 / 深色 / 跟随系统），右下角悬浮按钮切换。
- 存档可导出 / 导入 JSON（与开源版格式兼容，可互相迁移进度）。
- AI 连接配置在设置页（可选）：填自己的 API Key 或连接本地模型，Key 只存本机浏览器；AI 陪跑面板在路线图中，不配置也能完整游玩。
